# E-commerce & Shopping — Complete Personal Work

## Apps
- Fashion Store
- Beauty & Cosmetics Store
- Grocery Store
- Electronics Store

## Features
Amazon/AJIO-style marketplace UI, product catalogs, search, category filters, price filters, size/options, sorting, wishlist, cart, quantity controls, totals, checkout, payment options, order confirmation, order tracking, product comparison, responsive design and LocalStorage.

## Pages
Each page contains separate `index.html`, `style.css`, and `script.js`.

## Run
Open `ecommerce/fashion-store/home/index.html` with VS Code Live Server.
